Guide / Amazon returns

How to print an Amazon return label on 4×6

Amazon return labels are usually laid out for an ordinary printer: one full page with the carrier label on part of it and return instructions on the rest. Sent straight to a 4 × 6 thermal printer, that page shrinks. Crop the label first and it prints at full size.

Quick answer

Amazon return labels usually download as a full letter page, so a 4 × 6 thermal printer shrinks them. Save the label as a PDF, crop it onto a 4 × 6 page with the free 4×6 converter, then print at 100% with paper size 4 × 6. Some returns offer a QR code drop-off instead.

01 / Check firstDo you need to print a label at all?

For many returns, Amazon offers drop-off options with a QR code instead of a printed label. You show the code on your phone at the drop-off location and the staff there print or handle the label. Which options you see depends on the item, the seller and your address, so check the return methods Amazon lists before you print.

If a printed label is the only option, or you just prefer to label the box yourself, carry on below.

02 / Step by stepPrint the return label on a 4 × 6 thermal printer

  1. Start the return. In Your Orders, choose the item, start the return and pick a method that uses a printed label.
  2. Save the label as a PDF. When the label opens, download it or use your browser's print dialog with Save as PDF as the destination. Don't print it to the thermal printer yet.
  3. Crop it to 4 × 6. Open the PDF in the shipping label to 4×6 tool. It crops the carrier label onto a 4 × 6 page in your browser; the file is not uploaded to us.
  4. Check the result. The whole barcode, tracking number and address block should be on the page, with a little white space around the edges.
  5. Print at actual size. Choose your thermal printer, set the paper size to 4 × 6 in, select 100% or Actual size, and print one copy.

Keep the instructions part of the original page for yourself if it lists what to put in the box, such as a return code. You can print that page on plain paper, or just read it from the screen.

03 / Get it rightCropping tips for return labels

  • Never crop into the barcode. If the label area is close to the page edge, leave a margin rather than trimming tight.
  • Don't stretch it. A label that is narrower than 4 × 6 after cropping should print at its real size with white space, not be stretched to fill the page.
  • Watch the rotation. Some return labels sit sideways on the page. Rotate the cropped label so it is upright on the 4 × 6 page before printing.
  • Use one label per box. Each return label belongs to one return. Don't reuse it for a second package.

04 / If it still goes wrongCommon problems

The label prints tiny in one corner

The printer is still receiving a letter-size page, or the scale is set to Fit. Crop first, then print at 100%. Our printing-too-small guide shows where Rollo, Zebra and Munbyn drivers keep the paper size.

The thermal printer feeds blank labels

That is usually calibration or gap detection, not the PDF. Follow your printer's media-calibration steps.

I don't have a thermal printer

Print the original page at 100% on plain paper, cut out the label and tape it flat to the box. Cropping is only needed for 4 × 6 label stock.

What we verified: the crop-and-print steps are general guidance for full-page label PDFs. We have not tested every Amazon return type, and Amazon's return pages change over time. Label Ninja is independent and not affiliated with Amazon.
