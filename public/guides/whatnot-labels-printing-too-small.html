The print bench / troubleshooting

Whatnot labels printing too small?

Check the PDF page size, the printer's paper size and the print scale first. A mismatch can shrink a readable label into one corner or cut off its edges.

By the Label Ninja team · Updated September 6, 2026

Label typeSize checkOther symptomsOne-page test

01 / Start with the fileIs this a shipping label or an item number?

A shipping label contains the destination and carrier barcode. A numbered item label identifies something in your show. They can have different page sizes, even if you print both from the same computer.

For postage, Whatnot supports a 4 × 6 thermal format and an 8.5 × 11 standard-paper format. If your downloaded PDF is letter-size, choose the thermal format and download it again before printing on a 4 × 6 roll. See Whatnot's shipping-label instructions.

For numbered items, The Whatnot Labels maker creates a PDF with one number per page. Its available sizes are 1 × 0.5, 2 × 1 and 3 × 2 inches. Use the same size in the printer settings.

02 / Match all threeWhich print settings should I check?

1. PDF page dimensions

Open the downloaded file in a PDF viewer and inspect its page dimensions or document properties. Don't judge its size from how large it looks on your screen: zoom changes the preview, not the page.

2. Printer paper dimensions

Choose your thermal printer, then open its paper or media settings. Match the dimensions to the loaded stock. If necessary, create a custom paper size using the measurements on the roll's packaging.

Nominal stock names can be rounded. For example, 2 × 1 inches converts to 50.8 × 25.4 mm; a driver entry called 51 × 25 mm is slightly different. Rollo also notes that products sold as “4 × 6” can have different metric measurements. Check the actual stock rather than assuming the preset matches. Rollo's explanation of metric label sizes.

3. Scale and page layout

For a PDF already matching your stock, start at 100% or Actual size, with one page per sheet and no added margins. Turn off multiple-pages-per-sheet or booklet options. “Fit” can shrink the page to the driver's printable area.

Inspect the orientation before printing. Changing portrait to landscape is useful only when it aligns the PDF with the stock; rotating and shrinking together can conceal the original mismatch.

03 / Read the resultWhat if the label is cropped, blank or sideways?

Part of the number or barcode is missing

Check the PDF itself first. If it looks complete, compare its dimensions and orientation with the driver. For a shipping label, regenerate the correct format rather than cropping the carrier barcode to make it fit.

The printer feeds extra blank labels

Check how the roll is loaded and follow your printer model's media-calibration instructions. A feed or gap-detection problem needs a printer adjustment; enlarging the PDF text will not correct it.

The label feeds, but no text appears

Confirm that the material is compatible and the printable side faces the print head. Rollo requires direct-thermal labels; thermal-transfer stock will not work without a ribbon. Its guidance also calls for opaque paper with gaps or perforations. Check Rollo's stock and loading guide, or your own printer manufacturer's instructions.

Whatnot's automatic Sorting Labels never arrive

This is a different workflow from a downloaded PDF. Whatnot's Sorting Labels beta is limited to selected sellers and needs Whatnot Tray. Check eligibility and the official troubleshooting steps before changing a PDF setting. Whatnot Sorting Labels setup.

04 / Save the rest of the rollPrint one page before the full batch

Use the print dialog's page range to print page 1 only. Check the physical dimensions, orientation and edge clearance. If it fits, print the remaining pages from that same file.

For a Label Ninja number batch, changing printer settings or printing an existing PDF again does not spend another free batch. Exporting a new PDF with different label settings does. Once you have a working combination, record the stock, driver paper size and scale beside your printer.

On a phone, paper-size controls depend on the printer app. If you cannot find the needed size, try the same file in a desktop PDF viewer. Avoid resizing a screenshot of the PDF: use the original file.
