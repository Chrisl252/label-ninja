Whatnot labels printing too small? Here is the fix

A tiny label in one corner, a cut-off barcode or a sideways print almost always comes from one of three mismatches: the PDF page size, the printer's paper size or the print scale. Check them in that order.

Quick answer

Whatnot shipping labels print tiny when an 8.5 × 11 PDF is sent to a 4 × 6 thermal printer. Re-download the label in Whatnot's 4 × 6 thermal format, set the printer's paper size to 4 × 6, and print at 100% (Actual size), not Fit. For number labels, match the PDF size to your stock.

01 / Start at the sourceHow to change label size on Whatnot

Whatnot offers shipping labels in two formats: 4 × 6 for thermal printers and 8.5 × 11 for standard paper. If you print an 8.5 × 11 file on a 4 × 6 roll, the printer shrinks a whole letter page onto the label, which is the most common reason a Whatnot label comes out tiny.

  1. Open the shipment in Whatnot Seller Hub on a computer.
  2. When you generate or reprint the label, choose the 4 × 6 thermal format rather than 8.5 × 11.
  3. Download the label again and check the new PDF's page size before printing.

General guidance, not a verified walkthrough. Whatnot's menu wording can change and we have not tested every account type, so check Whatnot's shipping-label instructions for the current steps.

If you only have the letter-size PDF, the free shipping label to 4×6 tool crops it to a 4 × 6 page in your browser. It does not change or create postage; it only resizes the file you already have.

For numbered item labels, the size is set where you make them. In the Whatnot number labels maker, choose 1 × 0.5, 2 × 1 or 3 × 2 inches to match your stock.

02 / Check the fileIs this a shipping label or an item number?

A shipping label contains the destination and carrier barcode. A numbered item label identifies something in your show. They usually have different page sizes, even if you print both from the same computer, so the printer setting that works for one may shrink the other.

Keep a separate paper-size preset for each stock you use, and switch presets when you switch rolls.

03 / Match all threeWhich print settings should I check?

1. PDF page dimensions

Open the downloaded file in a PDF viewer and inspect its page dimensions or document properties. Don't judge its size from how large it looks on your screen: zoom changes the preview, not the page.

2. Printer paper dimensions

Choose your thermal printer, then open its paper or media settings. Match the dimensions to the loaded stock. If necessary, create a custom paper size using the measurements on the roll's packaging.

Nominal stock names can be rounded. For example, 2 × 1 inches converts to 50.8 × 25.4 mm; a driver entry called 51 × 25 mm is slightly different. Rollo also notes that products sold as “4 × 6” can have different metric measurements. Rollo's explanation of metric label sizes.

3. Scale and page layout

For a PDF already matching your stock, start at 100% or Actual size, with one page per sheet and no added margins. Turn off multiple-pages-per-sheet or booklet options. “Fit” can shrink the page to the driver's printable area.

Inspect the orientation before printing. Changing portrait to landscape is useful only when it aligns the PDF with the stock; rotating and shrinking together can conceal the original mismatch.

04 / Where the setting livesRollo, Zebra and Munbyn: where to set paper size

General guidance, not a tested walkthrough for each model. Driver screens differ by version and operating system.

  • Windows (most thermal printers): open Printers & scanners, choose the printer, then Printing preferences. The paper or stock size is usually there. Set it to 4 × 6 for shipping labels, or your number-label size, and save it as the default if you mostly print one size.
  • Mac: choose the printer in the print dialog and set Paper Size. If 4 × 6 is missing, add a custom size with zero margins.
  • Rollo: the driver and the Rollo app both expose a paper size list; check that the selected size matches the roll, including its metric measurement.
  • Zebra: on the ZDesigner driver, the label size is in the driver's printing preferences. A wrong stock size there will scale every print.
  • Munbyn and other 4 × 6 printers: look for paper size in the driver preferences and in the print dialog, then print at 100%.

Some sellers also find that their browser's built-in PDF viewer ignores driver settings. If prints stay small after you have matched everything, try the same PDF in a desktop PDF reader.

05 / Read the resultWhat if the label is cropped, blank or sideways?

Part of the number or barcode is missing

Check the PDF itself first. If it looks complete, compare its dimensions and orientation with the driver. For a shipping label, regenerate the 4 × 6 format or crop carefully so the whole carrier barcode stays on the page.

The printer feeds extra blank labels

Check how the roll is loaded and follow your printer model's media-calibration instructions. A feed or gap-detection problem needs a printer adjustment; enlarging the PDF text will not correct it.

The label feeds, but no text appears

Confirm that the material is compatible and the printable side faces the print head. Rollo requires direct-thermal labels; thermal-transfer stock will not work without a ribbon. Check Rollo's stock and loading guide, or your own printer manufacturer's instructions.

Whatnot's automatic Sorting Labels never arrive

This is a different workflow from a downloaded PDF. Whatnot's Sorting Labels beta is limited to selected sellers and needs Whatnot Tray. Check eligibility and the official troubleshooting steps before changing a PDF setting. Whatnot Sorting Labels setup. For how they differ from printed number labels, see Sorting Labels vs number labels.

06 / Save the rest of the rollPrint one page before the full batch

Use the print dialog's page range to print page 1 only. Check the physical dimensions, orientation and edge clearance. If it fits, print the remaining pages from that same file.

Once you have a working combination, write down the stock, driver paper size and scale and keep it beside your printer. Label Ninja's tools are free with no export limit, so remaking a PDF at a different size costs nothing but a minute.

On a phone, paper-size controls depend on the printer app. If you cannot find the needed size, try the same file in a desktop PDF viewer. Avoid resizing a screenshot of the PDF: use the original file.
