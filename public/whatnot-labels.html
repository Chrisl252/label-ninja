01 / Know the differenceWhatnot Sorting Labels vs manual number labels

Whatnot Sorting Labels are Whatnot's own feature. At the time of writing it is a beta for selected sellers: after an item sells, Whatnot Tray prints a label with sale details so you can sort sold items as the show runs. Whatnot decides who is eligible, and it is set up inside Whatnot. See Whatnot's Sorting Labels help page for eligibility and setup.

Manual number labels are what this page makes. You print a run such as #1 to #80 before the show, stick one on each item, bag or sleeve, and say the number on stream. They work for any seller, need no Whatnot access, and you match numbers to buyers yourself from your sales list.

02 / Same idea, different nameWhatnot number tags

"Number tags" usually means the same thing as number labels: a visible number on each item so viewers can call out what they want and you can find it fast. Some sellers print them on small thermal labels; others put a larger number on a bag or a card.

  • Small items or cards: 1 × 0.5 in labels keep the number out of the way.
  • Bags and sleeves: 2 × 1 in is a common middle size and is the default here.
  • Readable on camera: 3 × 2 in gives the largest number, which helps viewers read it on stream.

Use a prefix to keep shows apart, for example A for one show and B for the next, or continue the range (201–400) from a previous run. Whichever you choose, keep the same number in your own sales list so you can pack orders after the show.

05 / Print one page firstHow do I print the labels at the right size?

  1. Choose the stock and number range above. Open the settings in the studio and download your PDF.
  2. Open the PDF in a viewer with paper-size controls. Choose your thermal printer and the matching label dimensions.
  3. Select 100% or Actual size, one PDF page per label, and no added margins. Check the orientation in the preview.
  4. Print only page 1. Measure it against the stock before printing the remaining pages from the same PDF.

If the result is tiny, rotated or cut off, follow our guide to Whatnot labels printing too small before changing font size.

06 / Before your showCommon questions

Is it really free?

Yes. The Whatnot label maker and the rest of Label Ninja's tools are free to use, with no quota on how many PDFs you make and no paid plan. The site is supported by ads.

How many labels fit in one PDF?

Up to 200 numbers per PDF, numbered between 1 and 999. For a bigger show, make a second PDF that continues the range, for example 201–400.

Can I use a different prefix or continue an earlier run?

Yes. Use a short prefix such as C or SHOW-, or leave it blank. To continue after #200, set the next range to start at 201.

Can I use my phone?

You can set up the labels and download the PDF on a phone. Printing depends on your printer's mobile support and app. If its print dialog cannot set the right paper size, open the same PDF on a computer.

Can this print shipping barcodes or buyer names?

No. This feature creates sequential item numbers only, and it does not know which buyer purchased an item. Use Whatnot's own shipment tools for addresses and postage.

Does this work with Whatnot Sorting Labels?

They are separate. Label Ninja does not connect to Whatnot, so it cannot print Sorting Labels or read your sales. You can still use number labels alongside them.

Ready for your next show?

Set the range, check the first label in the preview, and download the PDF. It takes about a minute.
